QUICKCHAT - NETBEANS MAVEN PROJECT

Requirements:
- JDK 17 or newer
- NetBeans with Maven support

Open:
1. Extract QuickChatNetBeans.zip.
2. In NetBeans choose File > Open Project.
3. Select the extracted QuickChatNetBeans folder.
4. Allow Maven to download JUnit dependencies.
5. Run QuickChat.java, or right-click the project and choose Run.
6. Run tests by right-clicking the project and selecting Test.

Files:
- src/main/java/com/mycompany/quickchat/Message.java
- src/main/java/com/mycompany/quickchat/QuickChat.java
- src/test/java/com/mycompany/quickchat/MessageTest.java

Notes:
- The login flag in QuickChat.java is a demonstration placeholder. Connect your actual Login class before submission.
- The messages.json file is written to the program's working directory.
- This is a starter implementation based on the requirements visible in the recording. Check it against your full assignment brief before submission.
